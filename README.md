# نظام إدارة المزرعة (Angular 19)

```bash
npm install
npm start          # http://localhost:4200
npm run build      # الناتج في dist/farm/browser
```

## النشر على GitHub Pages
1. ارفع المشروع على مستودع GitHub (الفرع main).
2. Settings → Pages → Source: GitHub Actions.
3. بعد أول push سيظهر الرابط: https://USERNAME.github.io/REPO/

## إضافة قسم جديد
أضف مفتاحاً جديداً في `src/app/config.ts` (كائن M) وسيظهر تبويب وجدول ونموذج تلقائياً.

## الدخول والصلاحيات (نسخة تجريبية)
أول فتح: ينشئ حساب المدير. المدير يدخل بالإيميل فقط. باقي الأدوار بالإيميل أو التليفون.
المدير يضيف الفريق ويعدل الصلاحيات من تبويب «الصلاحيات».
تنبيه: التحقق برسالة SMS وإرسال إيميل غير مفعّلين، ويحتاجان سيرفر.
